# Linear Traversal (Linear Scan)

## Definition
Linear Traversal is a fundamental algorithmic technique in which we visit each element of a data structure sequentially, usually from the first element to the last element.

---

## Common Data Structures
Linear Traversal is commonly used with:

1. Arrays
2. Strings
3. Linked Lists

---

## Purpose
The main purposes of linear traversal are:

- Access every element
- Search for a value
- Find maximum or minimum
- Count occurrences
- Compute sums
- Update elements

---

## Example Problems
Some common problems solved using linear traversal:

- Find Maximum Element in an Array
- Find Minimum Element in an Array
- Linear Search
- Count Even and Odd Numbers
- Sum of Array Elements
- Find Frequency of Elements

---

## How It Works
Start from the first element (index `0`) and process each element one by one until reaching the last element.
